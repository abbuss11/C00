# C00
C00 – Initiation au Bash

Ce dépôt contient des exercices d’initiation à la programmation en Bash.

Exercices inclus

1. `hello_world.sh` – Affiche "Hello, World !"
2. `current_datetime.sh` – Affiche la date et l’heure actuelles
3. `list_files.sh` – Affiche les fichiers du répertoire courant
4. `create_directory.sh` – Crée un répertoire nommé `test_directory`
5. `check_file_exist.sh` – Vérifie si un fichier existe
